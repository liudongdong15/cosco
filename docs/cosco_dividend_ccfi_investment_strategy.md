# 中远海控股息率、回购与 CCFI 投资策略总结

## 1. 策略目标

本策略用于辅助判断中远海控的持仓性价比和加仓条件，核心不是预测股价，而是围绕“股东回报能否覆盖底线收益要求”建立纪律化框架。

策略主线：

- 先用股息率和回购比例判断基础安全垫。
- 再观察周度 CCFI 是否明显回升，用来确认利润周期胜率是否改善。
- 如果 CCFI 没有明显回升，则重点检查 CCFI 对应的利润预测是否会跌破压力股息率底线。
- 当压力情景下的股息率被击穿时，降低主动加仓意愿，转入观察或防守。

本文件是个人策略框架整理，不构成投资建议，不给出目标价或买卖结论。

## 2. 核心定义

### 2.1 预期股息率

预期股息率是正常情景下的分红收益率。

```text
预期股息率 = 预期每股股利 / 当前股价
```

其中，预期每股股利可以来自：

- 公司已公告的年度分红方案。
- 基于预期归母净利润和分红比例推算的每股股利。
- 最近几年稳定分红比例的保守估计。

预期股息率更偏“正常情景收益率”，适合衡量当前价格是否具备吸引力。

### 2.2 压力股息率

压力股息率不是预期股息率，而是“利润下行压力情景下，仍然希望守住的最低股息率”。

当前策略参数：

```text
总股本 = 153.1 亿股
压力股息率底线 = 6%
```

压力股息率用于反推最低可接受利润：

```text
压力每股股利 = 当前股价 * 6%
压力分红总额 = 当前股价 * 153.1 亿股 * 6%
压力利润底线 = 压力分红总额 / 假设分红比例
```

如果用变量表示：

```text
P = 当前股价
S = 总股本，当前为 153.1 亿股
Y = 压力股息率底线，当前为 6%
R = 假设分红比例

压力每股股利 = P * Y
压力分红总额 = P * S * Y
压力利润底线 = P * S * Y / R
```

说明：当 `S` 使用“亿股”、`P` 使用“元/股”时，分红总额和利润底线的单位为“亿元”。

示例测算，仅用于说明公式：若当前股价为 `14.02 元/股`，压力股息率为 `6%`，总股本为 `153.1 亿股`：

| 假设分红比例 | 压力每股股利 | 压力分红总额 | 对应归母净利润底线 |
| --- | ---: | ---: | ---: |
| 40% | 0.84 元/股 | 约 128.8 亿元 | 约 322.0 亿元 |
| 50% | 0.84 元/股 | 约 128.8 亿元 | 约 257.6 亿元 |
| 60% | 0.84 元/股 | 约 128.8 亿元 | 约 214.7 亿元 |

策略上可把 `50%` 分红比例作为中性口径，把 `40%` 作为偏保守口径。

### 2.3 回购比例

回购比例用于补充分红视角，衡量公司是否通过回购增强股东回报。

```text
回购比例 = 年度回购金额 / 当前或年度平均市值
股东回报率 = 预期股息率 + 回购比例
```

使用原则：

- 分红是更直接的现金回报，应作为主指标。
- 回购金额具有时点性和管理层择时特征，应作为加分项。
- 若回购发生在低 PB、低估值区间，信号质量更高。
- 若回购规模较小，不能替代股息率安全垫。

## 3. CCFI 周度观察框架

CCFI 是中远海控盈利周期的关键先行观察变量。策略中不只看年度 CCFI 均值，也观察周度 CCFI 是否出现趋势性修复。

### 3.1 “明显回升”的操作定义

建议至少同时观察以下信号：

| 信号 | 说明 | 策略含义 |
| --- | --- | --- |
| 最新 CCFI 高于 13 周均线 | 当前运价高于中期均值 | 短期环境改善 |
| 4 周均线高于 13 周均线 | 短周期趋势强于中周期趋势 | 回升更具持续性 |
| 最近 4 周均线斜率为正 | 连续数周向上 | 避免单周噪音 |
| 最新 CCFI 较 13 周低点回升 10%-15% 以上 | 从底部脱离 | 胜率改善 |
| 周度数据缺口不影响判断 | 缺失周不能被当作连续走势 | 避免误判 |

满足条件越多，CCFI 回升信号越强。若只出现单周跳升，但 4 周均线和 13 周均线仍未改善，应视为观察信号，而不是确认信号。

### 3.2 CCFI 与利润底线

当 CCFI 未明显回升时，策略重点转向压力测试：

```text
CCFI 情景 -> 归母净利润预测 -> 可分红金额 -> 压力股息率
```

判断顺序：

1. 根据当前 CCFI 水平和历史 CCFI/利润关系，形成保守利润情景。
2. 用假设分红比例计算可分红总额。
3. 将可分红总额除以总股本，得到压力情景下的每股股利。
4. 用压力每股股利除以当前股价，得到压力股息率。
5. 若压力股息率低于 `6%`，说明底线收益被击穿。

简化公式：

```text
压力情景每股股利 = 压力情景归母净利润 * 假设分红比例 / 153.1 亿股
压力情景股息率 = 压力情景每股股利 / 当前股价
```

## 4. 仓位决策框架

策略可以拆成四种状态：

| 状态 | 股息率/回购 | CCFI 周度趋势 | 策略动作 |
| --- | --- | --- | --- |
| 防守观察 | 压力股息率低于 6% | 未明显回升 | 不主动增加仓位，等待价格或 CCFI 改善 |
| 价值观察 | 压力股息率高于 6% | 未明显回升 | 保持观察，重点跟踪利润底线是否稳定 |
| 趋势确认 | 压力股息率高于 6% | 明显回升 | 胜率改善，可考虑提高仓位比例 |
| 高风险反弹 | 压力股息率低于 6% | CCFI 初步回升 | 等待趋势确认，不因单周反弹过早提高仓位 |

更具体地说：

- 加仓优先级最高的情况：压力股息率仍高于 `6%`，且 CCFI 周度趋势出现多信号确认。
- 观察优先级最高的情况：压力股息率仍高于 `6%`，但 CCFI 未明显回升。
- 风险控制优先级最高的情况：CCFI 预测利润跌破压力利润底线，导致压力股息率低于 `6%`。

## 5. 当前需要重点跟踪的变量

基础参数：

- 总股本：`153.1 亿股`
- 压力股息率底线：`6%`
- 中性分红比例假设：`50%`
- 保守分红比例假设：`40%`

每周跟踪：

- 最新 CCFI 周均值。
- CCFI 4 周均线。
- CCFI 13 周均线。
- 最新 CCFI 相对 13 周低点的反弹幅度。
- 是否存在春节、国庆等缺失周造成的图表断点。

每季或公告后跟踪：

- 归母净利润。
- 经营现金流。
- 每股股利。
- 回购金额。
- 归母权益和 PB。
- 有息负债变化。

## 7. 策略纪律

执行时保持三条纪律：

1. 不因为低 PE 单独提高仓位。中远海控是强周期公司，低 PE 可能来自周期高点利润。
2. 不因为单周 CCFI 反弹直接确认周期反转。至少观察 4 周均线、13 周均线和底部反弹幅度。
3. 不把预期股息率当作压力股息率。真正的底线是利润下行后是否仍能支撑 `6%` 的压力股息率。
