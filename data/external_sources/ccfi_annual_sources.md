# CCFI Annual Average Source References

This file is the local provenance snapshot referenced by `source_url` for
`ccfi_average` rows. The values are annual averages for the China Containerized
Freight Index (CCFI), used as an external industry indicator in the COSCO Value
Line report.

## Source Contract

- `source_url` values in the metrics CSV point to anchors in this file using
  `file://data/external_sources/ccfi_annual_sources.md#YYYY`.
- Each entry records the value, calculation basis, and source family used during
  manual review.
- If a web source or raw weekly/monthly table is later archived, add the exact
  URL or local raw data path under the relevant year before changing the value.

## Annual Values
